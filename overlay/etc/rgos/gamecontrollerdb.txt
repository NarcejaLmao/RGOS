# SDL2 controller mapping for the RG34XX-SP buttons (gpio-keys "gpio-keys-joypad" built by tools/dtb_gpiokeys.py).
# Port scripts get it through SDL_GAMECONTROLLERCONFIG_FILE (set by rgos-session). Nintendo layout, so SDL / PortMaster
# button names match the labels printed on the hardware: right face button = "a" (the console's A), bottom = "b" (the
# console's B), top = "x" (the console's X), left = "y" (the console's Y).
# Button numbers follow evdev order (0=BTN_SOUTH ... 8=SELECT 9=START 10=FN 13-16=D-pad), same as retroarch.cfg.
