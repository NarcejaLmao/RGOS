# RGOS
RG OS is a completely free Debian based Linux emulation distribution for retro handhelds. The end goal of this project is to make free and well optimized Linux emulation distribution for many Retro Handhelds.

# Supported Devices
Anbernic RG34XXSP<br>
Anbernic RG35XXSP
